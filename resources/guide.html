反重力设置速查

按 Ctrl + Alt + F8 切换中文覆盖。双击托盘图标可打开星轨启动器。

General · 通用
Interface Layout 切换简洁写作布局或完整开发布局。Request Review 表示敏感操作按权限规则请求确认。Queue 将追加消息排到本轮之后，Send Immediately 会尽快介入当前任务。
Application · 应用
Prevent Sleep 用于长任务期间保持电脑清醒。Keep In Menu Bar 允许关闭窗口后继续运行。若要重新加载代理，请先从托盘完整退出反重力。
Appearance · 外观
Theme 切换明暗主题，Font Size 调整字号，Conversation Width 调整聊天区域宽度。部分高级选项随版本和账号而异。
Shortcuts / Notifications · 快捷键和通知
搜索动作名称可查看或修改按键。系统通知和提示音可以分别开启，提示音音量与语音播报音量独立。
Models · 模型用量
Model Quota 显示使用额度。Enable AI Credit Overages 允许在常规额度用完后使用积分。
Browser · 浏览器
Open Links In 选择打开链接的位置。Download Location 设置下载目录。Browser Actuation Rules 控制智能体可以操作的网站。
Projects / Account · 项目和账户
项目可以继承全局权限或设置单独规则。账户页管理登录、数据偏好及套餐。
Customizations · 自定义
Marketplace 可以查看可用插件，Installed 列出已安装项目。插件名称保持原文，便于对照官方文档。
